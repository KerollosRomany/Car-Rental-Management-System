🚗 Car Rental Management System

A web-based Car Rental Management System that streamlines the rental process for both customers and employees.

Customers can browse available vehicles, check availability, make rental reservations, and manage their rental history. Employees can manage vehicles, customers, rentals, payments, and vehicle returns through a centralized system.

🎯 Project Overview

The Car Rental Management System is designed to simplify and organize the complete car rental workflow through a centralized platform.

Instead of relying on manual processes or disconnected records, the system provides an organized solution for managing:

- 🚗 Vehicle availability and information
- 👤 Customer accounts and information
- 📅 Rental reservations
- 💳 Rental payments
- 🔄 Vehicle returns
- 📋 Rental history

✨ Main Features

👤 Customer

- Create an account and manage their profile
- Browse available vehicles
- Check vehicle availability for selected dates
- Make rental reservations
- View rental history

👨‍💼 Employee

- Manage vehicles
- Manage customer records
- Manage rental reservations
- Manage payments
- Process vehicle returns
- View rental history

🛠️ Development Plan

The project is planned to be developed over 6 weeks. Development and testing will run in parallel, allowing each completed module to be tested before moving to the next stage.

Week| Focus Area| Key Activities| Deliverable
1| Requirements, Architecture & Database| Requirements analysis, use cases, ERD, entity relationships, project architecture, database setup, UI/UX foundation| Requirements, ERD, architecture and initial UI design
2| Authentication & Customer Management| Registration, login, authentication, authorization, customer profiles, driving license information| Working authentication and customer management
3| Vehicle Management| Vehicle CRUD, categories, rental rates, vehicle status, vehicle details| Complete vehicle management module
4| Availability & Reservations| Availability checks, date validation, reservation creation, rental status, double-booking prevention| Working reservation and availability system
5| Returns, Payments & Rental History| Vehicle pickup and return, payment management, rental history, integration between rental modules| Complete rental lifecycle
6| Integration, Testing & Finalization| End-to-end testing, regression testing, bug fixing, UI polishing, documentation, presentation and demo preparation| Fully integrated and demo-ready system

🧪 Testing Strategy

Testing will be performed continuously throughout the development process rather than being postponed until the final week.

- Week 1: Requirements and test-case preparation
- Week 2: Authentication and authorization testing
- Week 3: Vehicle management testing
- Week 4: Availability and reservation testing
- Week 5: Complete rental workflow testing
- Week 6: End-to-end, integration and regression testing

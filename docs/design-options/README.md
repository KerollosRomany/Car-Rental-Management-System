# Design options

The front end uses **palette 4, Cloud Cobalt**, and **logo C3, the Wayfare plate**. The rest is kept in case the team changes its mind.

- `palettes/` has CSS that overrides the colour tokens of `wayfare-frontend/assets/css/tokens.css`. Palette 4 is what the front end now uses. Palette 5, Golden Shore, is a sand, sea and gold alternative for Hurghada.
- `logos/` has SVG files for six logo options, each with an `-on-dark` version. C1 Route, C2 Fold, C3 Plate and C4 Fork go with Cloud Cobalt. G1 Sunwave and G2 Coast go with Golden Shore.

The old orange look is in the Git history before the "Cloud Cobalt palette" commit.
